3️⃣ THE 4 PILLARS OF LEARNING (HELD)

🧠 HEAD (35%) - Kamu Harus PAHAM

5 Langkah Troubleshooting:

1. IDENTIFIKASI GEJALA
   • Apa yang salah? (lampu mati, alarm aktif)

2. KUMPULKAN DATA
   • Cek HMI, multimeter, logbook

3. ANALISIS PENYEBAB
   • Buat daftar kemungkinan akar masalah

4. UJI HIPOTESIS
   • Isolasi satu per satu komponen

5. PERBAIKI & VERIFIKASI
   • Pastikan sistem normal kembali

🔧 HAND (30%) - Kamu Harus BISA

Contoh: Generator Tidak Bisa Start

Gejala: Tombol start tidak responsif

Langkah:
1. Cek power supply → OK?
2. Cek interlock oli → tekanan cukup?
3. Cek level air pendingin → aman?
4. Cek error code di HMI
5. Jika semua OK → cek relay start

4️⃣ MATERI INTI: MENJADI DETEKTIF SISTEM

Di kapal, **masalah jarang datang sendirian**. Satu gangguan bisa memicu efek domino:

  • Kabel putus → sensor gagal → PLC salah baca → pompa mati → mesin overheat

Tugas engineer bukan hanya **memperbaiki**, tapi **menemukan akar masalah**.

Gejala vs Akar Masalah:
- **Gejala**: Lampu panel mati
- **Akar masalah**: Sekring utama putus karena korsleting di kabel lampu
Jika hanya ganti lampu, masalah akan kembali!

Analogi Sederhana: Sakit Perut

Dokter tidak langsung kasih obat. Dia tanya:
- Kapan mulai sakit?
- Makan apa tadi?
- Ada demam?
Baru setelah analisis, dia tentukan: keracunan atau maag.
**Engineer harus seperti dokter — jangan asal tebak!**

❤️ Cerita Nyata: Engineer Selamatkan Kapal dengan Analisis Tepat

Kejadian:
Di kapal tanker, generator sering mati sendiri. ABK ganti relay berkali-kali — tetap error.
Engineer baru cek logbook, ternyata **tegangan turun drastis tiap jam 10 pagi**.
Ternyata: saat itu pompa muat hidup → beban melonjak → AVR tidak sanggup.
Solusi: atur sequencing start pompa.

Pelajaran:
Jangan fokus pada gejala — cari pola & akar masalah.
Data historis = kunci diagnosis akurat.
